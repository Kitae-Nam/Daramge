# 2페이즈 전투 보완

## 전환 시 검 보충

`PhaseTwoEncounter`가 공격·투척을 정리하고 전투를 차단한 뒤 `PhaseTwoSwordReplenisher`를 호출한다.
보충 컴포넌트는 프리팹에서 새 검을 생성하고 Inventory에 등록하는 역할만 맡는다.
살아 있는 검은 유지하며 빈 슬롯을 제거하고 여섯 자루에 부족한 만큼만 생성한다.
인스턴스별로 한 번만 실행하므로 이후 파괴한 검은 다시 생성되지 않는다.
주요 세 보스 프리팹에 Sword 프리팹과 목표 수 6을 연결했다.

## 실제 플레이어 넉백

기존 `BossPlayerHealthBinding`이 실제 타깃 루트의 CharacterController를 찾아
`PlayerKnockbackMovement`와 기존 `KnockbackReceiver`를 조립한다.
수신자는 방향·속도·남은 시간만 관리하고 이동 어댑터는 고정 프레임마다 추가 수평 이동을 적용한다.
CHG의 입력·중력·점프 상태를 덮어쓰지 않고 CharacterController 충돌 처리를 사용한다.
따라서 포효로 밀리는 동안 기존 `RoarWallImpact`의 벽 접촉도 발생한다.
CHG 파일과 플레이어 프리팹은 수정하지 않는다.

## 순차 투척

2페이즈의 Throw Count만큼 한 자루씩 경고·준비·발사·착지 대기를 반복한다.
첫 경고 시간은 기존 Warning Duration, 두 번째부터는 Repeat Warning Duration을 사용한다.
각 경고 시작에 최신 플레이어 위치를 저장하고 경고 도중에는 추적하지 않는다.
기존 Throw Spread는 동시 산개 투척에 쓰던 데이터로 남아 있으나 순차 패턴에는 사용하지 않는다.

Controller는 패턴 인스턴스를 소유자로 기억한다. 같은 연속 공격만 박힌 검을 남긴 채
다음 검을 준비할 수 있고, 다른 패턴은 기존처럼 박힌 검이 남으면 새 투척을 시작할 수 없다.
그로기·컷신·사망으로 정리되면 소유권도 폐기한다. 정상 완료에서는 박힌 검의 기존 회수 수명을 유지한다.
비행 연출은 기존 상승·이동·수직 낙하를 그대로 사용한다.

## 근접 검 교대

Inventory가 마지막 선택 다음 위치부터 공전 중인 검을 찾는다.
각 타격 후 원래 부모·회전·크기를 복원하고 다음 검을 장착한다.
사용 가능한 검이 한 자루면 그 검을 다시 사용할 수 있다.
공전 코드는 Held 상태 때문에 전체 정지하지 않고 Orbiting 상태인 검만 계속 갱신한다.

## 검증 범위

`ChessPhaseTwoTests`에 전부 파괴 후 보충, 기존 검 보존, 전환 후 추가 보충 금지,
타격별 검 교대, 순차 투척과 재조준, 취소 시 복원, 실제 CharacterController 넉백·벽 피해 테스트를 추가했다.
기존 테스트의 2페이즈 검 수 기대값은 6으로 갱신하고 검 파괴 테스트는 고정 대기 대신 실제 착지를 기다린다.
별도 검증 프로젝트는 Unity가 무시하는 `Validation~` 안에서 실행하므로 주 프로젝트의 열린 씬을 종료하지 않는다.

Unity 6000.6.3f1 별도 프로젝트에서 `ChessPhaseTwoTests` PlayMode 21개가 모두 통과했다.
새 통합 테스트 6개에는 실제 CharacterController의 이동·벽 접촉과 연속 투척의 재조준이 포함된다.
실제 DEV_SCNE_3의 카메라 구도와 공격 연출을 눈으로 확인하는 플레이 검증은 별도로 필요하다.
