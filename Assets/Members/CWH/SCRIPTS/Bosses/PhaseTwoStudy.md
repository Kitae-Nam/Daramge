# 검 공격 개선과 검은 킹 2페이즈

## 공격과 잔상

- 첫 경고 시작에 Inventory에서 검 한 자루를 확보하고 피벗에 장착한다.
- 경고 시간의 앞 80%는 Y축으로 검을 뒤로 당기고 나머지 20%는 준비 자세를 유지한다.
- 1페이즈는 기본 0.15초 동안 가로 베기를 두 번 한다. 베기는 빠르게 출발해 끝에서 감속한다.
- 검이 정면을 통과하는 프레임에 기존 부채꼴 피해를 한 번 적용한다. 피해를 검보다 먼저 주지 않는다.
- 각 베기 후 0.1초 동안 끝 자세를 유지한다. 두 번째 공격도 별도 경고와 차징이 있다.
- 실제 피해 판정은 부채꼴이며 칼날 콜라이더 기반 판정으로 변경한 것은 아니다.

`SwordSwingTrail`은 검 아래에 있는 파티클 시스템과 TrailRenderer를 찾아 베기 중에만 재생한다.
사용자가 만든 `Boos Slash Trail Effect`의 색, 머티리얼, 모양은 그대로 쓴다.
정상 베기 종료는 새 방출만 멈추고, 장착/반환/중단 시에는 기록도 지워 순간 이동 선을 막는다.
이 컴포넌트는 이펙트만, Presentation은 자세만, Pattern은 공격 순서와 판정 시점만 맡는다.

`finally`와 `Cleanup()`이 같은 반환 함수를 사용한다. 첫 경고 중 취소, 베는 중 그로기,
컷신, 사망 모두 검의 부모/자세/상태를 복원하고 공전을 재개한다.
이미 확보한 마지막 검도 `CanExecute()`가 인정하므로 검 한 자루만 남아도 공격할 수 있다.

## 실제 검 투척

Inventory가 있는 보스는 검 프리팹을 생성하지 않고 공전 중인 실제 검을 던진다.
투척 검에는 박혔을 때 켜지는 별도의 피격 콜라이더와 BreakableHealth가 연결된다.
박힌 검을 파괴하면 실제 검이 삭제되고 보스 추가 피해와 그로기가 한 번 적용된다.
자연 회수/전투 중단은 살아 있는 검을 공전으로 반환하며 파괴 보상을 주지 않는다.
파괴된 검을 자동 재생성하는 규칙은 넣지 않았다. 검이 없어지면 검이 필요한 패턴은 선택되지 않는다.
공전 목록이 없는 기존 프리팹을 위한 일회용 투척 프리팹 경로는 호환용으로 남겨 두었다.

## 2페이즈

HP가 정확히 60% 이하가 되면 현재 공격, 소환체, 투척 검을 정리하고 전환 잠금을 건다.
검은 킹 메시/머티리얼로 변경한 뒤 기본 2초가 지나면 같은 AI가 전투를 재개한다.
전환 잠금은 컷신 잠금과 별개이므로 컷신이 남아 있으면 공격/추적이 재개되지 않는다.
기존 `PhaseOneBrain` 이름은 씬 참조 보존을 위해 유지했지만 이제 두 페이즈에서 패턴을 선택한다.

보스의 **Chess Combat Profiles > Phase Two**에서 공격 수치를 조절한다.
전환 시간은 **Phase Two Encounter > Transition Duration**, 외형은 **Chess Phase Appearance**에서 조절한다.
검의 각도/차징 곡선은 **Melee Motion Source > Motion**을 사용한다.
책임 분리와 읽는 순서는 `Assets/Members/CWH/SOLID_Study_Guide.md`에 정리했다.

| 항목 | 기본값/동작 |
|---|---|
| Damage Multiplier | 근접/직접 대쉬 피해 1.35배 |
| Melee Strikes | 3연격 |
| Swing Duration / Combo Warning | 0.13초 / 0.6초 |
| Dash Speed Multiplier | 1.2배 |
| Dash Hazard Lifetime | 실제 이동한 길에 5초 동안 장판 유지 |
| Dash Hazard Damage / Tick Interval | 0.75초마다 10 피해. 콜라이더 중복 피해 방지 |
| Throw Count / Spread | 남은 검 중 최대 3자루, 목표 주변 3유닛 분산 |
| Roar Radius / Push Speed / Duration | 씬 기준 10유닛 / 35 / 0.6초 |
| Roar Wall Damage / Wall Layers | 밀치기 중 실제 벽 접촉 시 한 번 35 피해. 바닥/트리거 제외 |

폰/나이트에 검은 룩과 비숍을 추가했다. 한 번에 같은 종류 두 마리, 생존 기물이 있으면 재소환 금지,
보스 피해 50% 감소 규칙을 유지한다. 룩은 월드 X/Z의 직선 네 방향,
비숍은 대각선 네 방향 중 목표와 가까운 방향에 좁은 부채꼴을 예고하고 공격한다.
폰/나이트의 이동과 점프 방식은 유지한다.

벽 충돌 감지는 Rigidbody 접촉 또는 CharacterController 접촉을 사용한다.
기존 `IKnockbackReceiver`가 이동을 담당하고 `RoarWallImpact`는 한 번의 벽 피해만 담당한다.
Transform을 직접 옮겨 콜라이더를 통과시키는 외부 이동기는 자체 접촉 전달이 필요하다.

## 연결과 확인

DEV_SCENE과 PhaseOneBoss 프리팹에 실제 검과 페이즈 전환을 연결했다.
DEV_SCENE에 없었던 소환/투척/기물 보호 컴포넌트와 경고 표시를 추가하고 AI 목록에 연결했다.
씬에 배치된 네 검의 기존 이펙트 오버라이드는 유지한다. 기본 프리팹도 동일 이펙트를 참조한다.
새 기물/머티리얼과 코드는 모두 Assets/Members/CWH 아래에 둔다.

시각 확인 항목: 두 타격의 궤적 방향, 검 손잡이 위치, 저프레임에서 잔상 밀도,
전환 후 검은 킹 크기, 장판의 지면 높이, 벽/모서리 포효 충돌을 확인한다.
이펙트가 과하면 원본 머티리얼을 덮어쓰지 말고 CWH의 작업용 에셋에서 조절한다.

검증용 프로젝트/로그는 `Assets/Members/CWH/Validation~`에 보관한다.
Unity가 `~` 폴더를 임포트하지 않으므로 게임 어셈블리와 분리된다.

2026-11-01, Unity 6000.6.3f1의 별도 프로젝트에서 기존 회귀 검사와 새 검/2페이즈 검사를 합쳐
PlayMode 65개가 통과했다. 마지막 검의 차징, 피해 시점, 중단 정리, 실제 검 파괴/회수,
3연격, 다중 투척, 전환 잠금, 실제 Rigidbody 벽 접촉, 장판 피해를 포함한다.
검증한 Runtime/테스트 소스와 현재 소스의 내용이 동일한지도 확인했다.
전체 DEV_SCENE의 화면 연출과 시각적 밸런스까지 자동 검증한 것은 아니므로 실제 게임 뷰에서 확인한다.

이후 SOLID 리팩터링으로 검 복귀, 동작 데이터, 페이즈 설정/외형/소환 후보, 기물 행동, 장판 표시를 분리했다.
리팩터링 후 동일 Unity 버전에서 기존 65개와 교체 가능성 검사 7개를 합쳐 PlayMode 72개가 통과했다.
